# Checklist para adicionar um jogo

- [ ] Criar um namespace exclusivo.
- [ ] Converter `setup()` para `begin()`.
- [ ] Converter `loop()` para `update()`.
- [ ] Remover qualquer segundo `setup()` ou `loop()`.
- [ ] Expor um `Arcade::GameDefinition`.
- [ ] Adicionar o jogo ao `GameRegistry.cpp`.
- [ ] Confirmar que o nome cabe no menu de 160 × 128.
- [ ] Confirmar que o jogo usa rotação 3.
- [ ] Compilar todos os módulos juntos.
- [ ] Testar reinício físico para voltar ao menu.
