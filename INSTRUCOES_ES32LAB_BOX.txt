ES32LAB ARCADE v1.2.0 - INTEGRAÇÃO ES32 LAB BOX

1. Descompacte este ZIP na raiz do projeto ES32Lab_Arcade.
2. Confirme a mesclagem das pastas e a substituição dos arquivos existentes.
3. Compile o projeto completo pelo PlatformIO.
4. Para a primeira gravação ou caso o OTA não esteja disponível, use o ambiente:
   env:nodemcu-32s
5. Para atualizar pela rede, permaneça no menu até aparecer OTA:OK e use:
   env:nodemcu-32s-ota
